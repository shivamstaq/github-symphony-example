# Symphony Test Repo
This repository is used for integration testing of the Symphony orchestrator.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher (or the runtime appropriate for this project)
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/shivamstaq/github-symphony-example.git
   cd github-symphony-example
   ```

2. Install dependencies (if applicable):
   ```bash
   npm install
   ```

### Usage

Run the project:
```bash
npm start
```

### Running Tests

```bash
npm test
```
